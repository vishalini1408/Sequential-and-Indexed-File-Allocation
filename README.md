Experiment 14: Sequential and Indexed File Allocation

Program 1: Sequential File Allocation
File: seq.c
Compile and run:
gcc seq.c -o seq
./seq

Program 2: Indexed File Allocation
File: idx.c
Compile and run:
gcc idx.c -o idx
./idx

Observation:
Sequential allocation stores file blocks consecutively. Indexed allocation uses an index to locate blocks that may be stored in different disk locations.
